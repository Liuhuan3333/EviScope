# Style Guide

- 中文研究文档使用保守、可证伪的表达；英文论文使用 empirical software engineering 风格。
- 固定术语：claim、evidence package、evidence escalation、diff-conditioned alignment、repository-conditioned validity、selective release。
- 避免：novel、first、comprehensive、solve、prove，除非有直接证据。
- 每个结果同时报告原始计数、效应量与置信区间。
- correctness、utility、developer preference 三者始终分开。
- hallucination 仅用于复述已有工作或映射标签；本任务的主要术语是 support status 与 evidence sufficiency。
